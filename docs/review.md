Архитектура, оптимизации и активный бэклог репозитория `github:dryamovvv/pkgs`.

## 1. Архитектура и оптимизация под Raspberry Pi 5

Репозиторий представляет собой высокооптимизированный монорепозиторий пакетов для архитектуры **Arch Linux ARM (aarch64)**. Вся инфраструктура ориентирована на максимальную производительность на процессорах **Broadcom BCM2712 (Cortex-A76)**, используемых в Raspberry Pi 5.

### Аппаратная оптимизация (CFLAGS/CXXFLAGS/LDFLAGS)

Оптимизация компиляции задается в шаблонах `PKGBUILD` и применяется при сборках в контейнерах:

- **`mcpu=cortex-a76+crypto`**: Включает специфичный для Cortex-A76 набор инструкций (ARMv8.2-A), а также криптографические расширения (AES, SHA, PMULL), поддержку CRC, LSE (Large System Extensions), RDMA, FP16, Dot Product и RCPC. Это обеспечивает значительный прирост производительности по сравнению с обобщенным профилем `generic` ARMv8-A.
- **`-O2 -pipe`**: Оптимальный баланс производительности компилятора и результирующего кода с передачей промежуточных данных через конвейеры (без лишних дисковых операций).
- **`-Wl,-z,max-page-size=0x4000`**: Выравнивание сегментов ELF на **16 KB** (размер страницы памяти Raspberry Pi 5). Это критично для ядра `linux-rpi-16k`, так как ELF-файлы, скомпилированные с дефолтным выравниванием 4 KB, не смогут быть загружены на ядре со страницами 16 KB (приведет к ошибке сегментации при запуске).

### Специфичные оптимизации языков программирования

- **Rust**: `RUSTFLAGS="-C target-cpu=cortex-a76 -C opt-level=2"` транслирует оптимизации LLVM непосредственно под микроархитектуру Cortex-A76.
- **Go**: `GOARM64=v8.2` совместно с флагами компоновщика `-extldflags=-Wl,-z,max-page-size=0x4000` гарантирует корректную работу Go-бинарников на 16-килобайтных страницах.
