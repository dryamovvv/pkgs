# erd

A modern, cross-platform filesystem and disk-usage utility (binary: erd)

## Building

```bash
makepkg -s
```text

## Dependencies

- `gcc-libs`, `glibc` (runtime)
- `cargo` (build)

## Features

| Feature | Enabled | Description |
|---------|---------|-------------|
| standard | yes | Default Cargo build with RPi5 optimizations |
